# Firmware

## Build Requirements

- **IDE:** STM32CubeIDE 1.13
- **HAL:** STM32CubeF1 v1.8.x (generated by STM32CubeMX)
- **Programmer:** ST-Link V2 via SWD (SWDIO=PA13, SWDCLK=PA14)
- **Flash:** 64KB (STM32F103C8T6) — firmware uses ~32KB

## Quick Start

```bash
git clone https://github.com/AdnanAnwarAwan/Variable-Switching-DC-Power-Supply.git
cd Variable-Switching-DC-Power-Supply/firmware
```

Open `firmware/` folder in STM32CubeIDE as an existing project, build and flash via ST-Link.

## Key Tuning Parameters in main.c

| Constant | Default | Effect |
|---|---|---|
| `SWITCHING_FREQ_HZ` | 200000 | PWM frequency |
| `DEADTIME_COUNTS` | 14 | Gate dead-time (~194ns) |
| `SOFTSTART_STEPS` | 100 | Ramp steps × 50µs = 5ms |
| `FAN_ON_TEMP_C` | 50.0 | Fan start temperature |
| `SHUTDOWN_TEMP_C` | 85.0 | Thermal shutdown threshold |
| PID `Kp` | 0.8 | Proportional gain |
| PID `Ki` | 0.02 | Integral gain |
| PID `Kd` | 0.001 | Derivative gain |

## PID Tuning Guide

1. Start with Ki=0, Kd=0, increase Kp until output oscillates
2. Set Kp to 50% of oscillation value
3. Increase Ki slowly until steady-state error is eliminated
4. Add small Kd to reduce overshoot on load steps
5. Test with 0→5A load step — settle time should be < 1ms
